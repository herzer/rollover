The one rule this rests on — worth a yes or no first

How I read your rollover rule. In a run (same color, consecutive numbers), 13 may be followed by 1, so 12‑13‑1 and 13‑1‑2‑3 are valid runs. A run can start anywhere on the circle, but it is never longer than 13 tiles. Groups (same number, different colors) are unchanged. A 1 is always worth 1 point — for the 30‑point opening and for the end‑of‑round count. If any part of this is not how you and Mom play, say so in the note under question 3.
